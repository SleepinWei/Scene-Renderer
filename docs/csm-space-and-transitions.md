# CSM 的空间划分与平滑过渡

本文按当前工作区的 RHI 实现说明方向光阴影。交互三维示意采用 near=0.1 m、阴影距离=300 m、FOV=58°、宽高比=16:9；相机位置、太阳方向和 caster 范围为说明用途，不是实际场景帧捕获。示意改变重叠比例只影响示意，不会修改渲染器设置。

## 空间结构与渲染流程

CSM 沿相机的**线性视空间深度**将视锥切成五段，不是以相机为中心的五个球，也不是五个互不相交的光空间盒。每段有独立的方向光正交投影。相同 texel 数覆盖较小的近景范围，给近处更高的世界空间分辨率；远景牺牲精度换覆盖范围。

1. 从未抖动的相机矩阵还原视锥，截取到 `min(cameraFar, shadowSettings.distance)`，默认阴影距离 300 m。相机 far 可以为公里尺度，而阴影只覆盖指定范围。
2. 使用 70% 对数、30% 均匀的混合划分。设级数 N=5、near=n、有效阴影 far=f，第 i 个分界为：

   `s_i = 0.7 × n × (f/n)^(i/N) + 0.3 × [n + (f-n) × i/N]`

3. 为每段生成八个视锥角点，包括与前一级相接的重叠区域。用包围球确定稳定的光空间 XY 覆盖范围，然后扩展过滤边距，并将中心对齐阴影 texel 网格。
4. 光空间 Z 范围同时包含提交的 caster 包围盒与有效阴影视锥，避免只拟合接收面而漏掉来自相机视野外的投影物体。每级依据自己的光空间视锥剔除 caster；仍需上游提供足够的场景或地形几何。
5. 五级绘制到同一 atlas 的独立 tile。着色时先由 `-(shadowCameraView * worldPosition).z` 选择级联，再用对应矩阵投影并进行 PCF/PCSS 深度比较。tile 分辨率由 atlas 大小和所有光源所需的 tile 数共同决定，并非固定五张 2048²。

主要代码：[`ShadowRenderer.cpp`](../src/renderer/rhi/ShadowRenderer.cpp)，[`shadow-visibility.glsl`](../src/rhi/shaders/shadow-visibility.glsl)。未抖动矩阵在 [`ForwardPbrRenderer.cpp`](../src/renderer/rhi/ForwardPbrRenderer.cpp) 中保存，再传入 shadow pass；默认参数见 [`ForwardPbrRenderer.h`](../include/renderer/rhi/ForwardPbrRenderer.h)。

## 分界处怎样过渡

设当前级联深度段为 `[a,b]`，重叠比例 β 默认 0.1。混合区域为 `[b-β(b-a), b]`，下一段的 near 同时向前扩展到这个起点。这里只扩展下一段的前端，并非两级各扩展 10%。

在这个区域内，两级**分别**完成投影、偏移、深度比较与过滤，得到可见度 `V_i` 和 `V_(i+1)`：

```text
t = clamp((depth - (b - β(b-a))) / (β(b-a)), 0, 1)
w = t²(3 - 2t)                  // smoothstep
V = (1-w) × V_i + w × V_(i+1)
```

混合的是最终阴影可见度，不是两个深度值，也不是矩阵。分界前的 w 趋近 1，分界后的级联选择切到下一段，因此两边使用同一个下级可见度，避免级联切换引入数值跳变。smoothstep 在混合带两端的权重导数为零，避免权重本身引入突然的梯度变化。β=0 时直接切换，没有这项连续性保证。

最后一级没有更远的阴影图。当前实现从 `s_4 + 0.9 × (f-s_4)` 开始，平滑淡出至可见度 1。这里是**最后一段长度的末尾 10%**，不是全部阴影距离的末尾 10%。

## 稳定过渡还需要的配套措施

| 问题 | 当前实现 | 作用与边界 |
| --- | --- | --- |
| 分界后下一级没有有效数据 | 下一段包含上一段末尾的混合带 | 避免混到范围外返回的“全亮” |
| 移动、旋转时阴影爬动 | 未抖动视锥；包围球半径向上取整到 1/16 世界单位；光空间 XY 中心对齐 texel | 减少相机运动和 TAA 抖动导致的采样网格变化；太阳变化、投影变化仍可能改变阴影 |
| 不同级联出现错误 bias | 由接收面法线和每级投影解析求梯度，世界单位 bias 转换到对应深度空间 | 避免跨级联对已投影坐标做屏幕导数时混入不同矩阵；不保证所有几何的 acne/peter-panning 消失 |
| 软阴影跨级联宽度突变 | PCSS 由太阳角半径、线性光空间遮挡距离估计世界半影，再转换到当前级联 texel | 物理尺度一致；有限采样、最低一 texel 和最大过滤 texel 上限仍会造成近远级精度差异 |
| PCF/PCSS 读到相邻 atlas tile | 正交范围预留过滤 guard；所有采样约束在自己的 tile | 避免跨 tile 污染；guard 也能覆盖中心 snapping 的偏移 |
| 深度过滤错误 | 四 texel 分别比较，再对可见度双线性混合 | 避免先插值深度造成错误阴影边缘 |

这些措施保证的是合理覆盖下**级联切换的可见度连续**并减少闪烁，不能保证阴影完全无锯齿、无接缝或与光线追踪结果一致。重叠带只是把两个分辨率不同的估计平滑连接；增大重叠带会增加双级采样面积，也会扩大较低分辨率结果参与的位置。

## 下一步改进与验收

建议先保留默认 10% 重叠，优先完善实际场景可诊断性，而非直接增加级数。

1. **引擎内调试视图**：独立观察相机显示主相机的五段视锥、混合带、实际光空间盒；屏幕着色显示级联编号和混合权重。观察相机不能替代用于生成 CSM 的主相机，否则看不到固定划分。当前交互示意尚未接入引擎调试 pass。
2. **过滤尺度诊断**：显示每级米/texel、PCSS 实际世界半影和触顶比例。若分界差异主要来自过滤上限，研究相邻级共用世界空间半影上限，或提高不足级联的分辨率；仅增加混合宽度会隐藏而不会修正这类误差。
3. **自然大场景分层**：近景保留高分辨率 CSM，远山考虑独立远距阴影表示或低频近似。增加 shadow distance 会摊薄所有级联的近景精度；还要保证远处地形 caster 的提交与 LOD 能覆盖光空间需求。
4. **自动化验收**：平面接收面横跨四个分界；亚 texel 平移；相机旋转；缓慢移动太阳；低太阳高度；公里坐标；alpha caster；PCSS 大半影；阴影距离边界。分别测边界两侧可见度差、时间闪烁与 GPU 时间，在 Metal 与 Vulkan 对照。已有回归与历史结果见 [VT/CSM/PCSS 修复记录](vt-csm-pcss-fixes.md)，本次示意与文档更新未重新执行 GPU 回归。
