# PT 与实时渲染共享材质计划

2026-10-08。**本文的后续共享材质阶段尚未实施。** 已有 M1／M1-R 各向异性 GGX 的实现与验收保留在 [材质外观扩展](path-tracing-materials.md)。2026-10-09 的 [毛发与布料](path-tracing-fibers.md) 已交付 CPU／双后端 PT 闭包，但没有完成这里的 Raster 共享阶段。本文细化接下来的材质工作；自然环境应用的整体优先级见 [自然环境模拟路线](natural-environment-roadmap.md)。

目标是让同一个材质资产在 CPU PT、Metal／Vulkan GPU PT 和实时渲染中表达同样的表面结构与参数。共享材质模型不等于共享所有光传输算法：实时环境积分、阴影、透明层和体积输运仍需有明确预算的近似。OpenUSD／MaterialX 可作为未来导入入口，首轮不依赖它们，也不计划任意节点图。

## 已有基础与需要补齐的边界

| 路径 | 当前基础 | 后续缺口 |
| --- | --- | --- |
| CPU／GPU PT | 反射 GGX、方向性切线、玻璃／粗糙介电、薄叶、玉石／水介质、毛发、布料粗糙漫反射与有界 sheen；CPU 参考及双后端数值测试 | coat／多次散射 sheen 共享分层闭包、能量补偿、更多空间参数 |
| 原生实时主视图 | Forward／Deferred／Scene／透明表面接入 GGX；源切线与法线贴图；共享参数失效缓存与历史 | 分层、粗糙漫反射与薄叶的一致语义、环境照明质量和过滤 |
| 水体辅助捕获 | 使用共享 GGX shader | 源 corner tangent 尚未完整接入，当前仍由 UV 导数构帧；后续新增材质必须纳入反射／折射捕获 |
| 阴影／AO | 已有独立实时光照路径；RSM 默认关闭，仅保留 demo | alpha、双面、透射及层后底色需要相应规则，不能只更新主视图 |
| 地形／植被 | 材质 VT、岸线沙滩和程序化草地 | 将地表分层、叶片透射和动态湿度接入共享输入 |

入口主要是 [Material](../include/renderer/Material.h)、[GpuMaterial](../include/renderer/rhi/GpuMaterial.h)、[SceneSnapshot](../include/renderer/rhi/SceneSnapshot.h)、[PT SceneData](../include/PT/SceneData.h) 与 [实时材质 shader](../src/rhi/shaders/pbr-material.glsl)。当前 `MaterialExtension` 为 96 B；毛发／布料 PT 扩展后 `PackedMaterial` 从 208 B 增为 256 B，针织参数加入后为 272 B。这是现有 ABI，不预先决定下一版的大小。基础 Deferred 已有六个 MRT，新增参数必须先评估带宽与 attachment 上限，不能每加一个 lobe 就增加一张全屏缓冲。

## 数据与执行约定

以下名称是设计概念，尚未新增类型。

1. **MaterialInputs**：资产参数、贴图引用、单位与合法范围。颜色区分颜色空间，粗糙度与 mask 使用线性数据；旋转使用弧度；长度与介质系数沿用米及 1／米。默认值、缺失贴图和退化切线有统一规则。
2. **EvaluatedMaterial**：在表面上完成贴图与环境状态求值，生成 base／coat／fuzz／thin-transmission 等有限闭包及各自法线帧。PT 和实时共享字段语义，按执行路径提供适合的求值代码；不要求 CPU C++ 和 GLSL 共用源码。
3. **CapabilityProfile**：明确每个路径支持、近似或拒绝的功能。导入器输出转换报告，避免静默丢弃 coat normal 或透射参数。
4. **版本与失效**：资产版本、环境表面状态版本和 GPU 发布代际分别追踪。材质修改更新 Raster 缓存、PT scene identity 与相关历史；自然状态连续变化使用重投影／局部拒绝策略，避免每帧全局清空 TAA。固定 PT 捕获记录完整求值状态。

保留旧 JSON 和 legacy 材质入口；只有启用新模型才进入新分支。旧 clearcoat／SSS 不直接更名成已匹配的闭包，应先定义迁移映射与视觉差异。GPU 发布继续采用封存快照、分段上传与设备线程所有权。

## 分阶段交付

| 阶段 | 交付范围 | 完成条件 |
| --- | --- | --- |
| R0：共享输入与覆盖检查 | 参数 schema／兼容规则／路径能力表；补齐辅助捕获切线；准备线性 HDR fixtures、内存／shader 编译基线 | 同材质在主视图、实例、水体捕获和场景包中使用同参数；旧场景兼容；有可复现的成本报告 |
| R1：coat 分层 | 独立 weight、IOR、roughness、normal；底层透射衰减；CPU／GPU PT lobe 求值和采样；实时直接光与环境近似 | coat=0 退化；白炉、掠射、互易与正反 PDF；镜像／法线贴图；主视图与捕获一致；不靠叠加高光虚增能量 |
| R2：自然表面与薄叶 | 粗糙漫反射、薄叶反射／透射及双面语义；土壤、岩石、树皮、叶片参考资产 | 背光叶片、干湿表面、alpha 阴影和远景 coverage 稳定；PT／实时受控直接光对照；无暗面翻转与叶片闪烁 |
| R3：sheen／fuzz | 有界的表面纤维闭包；weight、颜色与粗糙度；与底层的能量分配 | 布料／苔藓类展示、掠射积分与独立参考；零强度退化；不把所有自然表面都套成布料 |
| R4：粗糙度与能量 | 微表面多次散射补偿、法线／粗糙度 footprint 过滤、环境积分改进 | 白炉收敛、粗糙材质不过度变暗；细法线运动序列稳定；固定环境预算和误差报告 |
| R5：空间状态与进阶透射 | coat／anisotropy 等参数贴图、地表湿度／积雪输入；按需求扩展方向性玻璃、导体复 IOR | 状态与贴图导出到 PT；边界混合与 VT 回退一致；透射 Jacobian／radiance 与 importance 规则独立验收 |

R0 → R1 → R2 是共享材质的首个可交付周期；R3／R4 按实际图像与预算推进。自然环境应用中，R2 和湿度接入的价值通常高于扩展车漆或薄膜，因此 R5 的湿度输入契约可在 R0 预留，基础湿度求值随应用阶段接入。R5 中更复杂的介电与光谱能力不阻塞这个周期。

coat 的首个模型采用可解释、能量受限的分层近似，不将其描述成完整层内随机游走解。PT 的采样 PDF 必须与实际求值对应；已有 BDPT 的连接、反向密度和光传输模式同步检查，不能只让单向 PT 看起来正确。实时 sheen／coat 环境光需独立验证，PT 的重要性采样不能直接作为固定八次采样的质量保证。

参考结构：[OpenPBR Surface 规范](https://academysoftwarefoundation.github.io/OpenPBR/) 区分底层、coat 与 fuzz，并分开描述材质结构和实现近似。本文借鉴其结构，不承诺参数完全兼容。GGX 求值与采样继续参考 [PBRT 微表面理论](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)。

## 实时路径的具体设计决策

- **Deferred**：先提交参数使用频率、G-buffer 位宽／格式和每像素成本表，再选择打包、材质 ID 查询或有限 variant。复杂透明／透射材质可走 Forward，但要明确可见性、深度与排序约束。
- **环境照明**：现有八方向天空采样作为基线，比较预过滤／查表与有限采样方案；各向异性、coat 两种法线和层间衰减分别验收，不默认用一张各向同性 LUT 覆盖所有闭包。
- **辅助视图**：shadow 的 alpha coverage、水体镜像／折射的完整材质同步纳入每一阶段。RSM 只保留既有 demo，不纳入后续材质阶段验收。材质需要依赖视角时，使用该捕获相机而非主相机。
- **自然表面**：湿度是环境输入，不只是全局降低 roughness。区分孔隙基底变暗、表面水膜与真正积水几何；积雪另有覆盖、法线与厚度，不能简单复用白色 coat。
- **光传输边界**：实时玉石／水体空间散射继续单独规划。更丰富的表面输入不自动解决多层透明、空间 BSSRDF 或实时多次间接光。
- **后端**：以 Metal／Vulkan 原生路径验收；OpenGL 保留可运行的降级语义，本机无法验证的 4.1 以后能力留待有设备时验收。

## 验收与成本门槛

每阶段先做无阴影／AO／时域／tone mapping 的受控线性 HDR 对照，再增加环境、间接光、透明、捕获和运动。数值验收关注半球能量、非有限值、退化行为、求值／采样一致性和 BDPT；展示图关注可辨认的外观，二者分别记录。

建立金属／塑料／清漆、粗糙岩石、干湿土壤、背光叶片、纤维六组小场景。参考资产需记录输入 hash、灯光、相机、采样数和随机种子；PT 收敛误差单独估计，不能将低采样噪声全部算作 Raster 材质误差。透射和环境近似设独立容差，直接光匹配与完整画面相似度不混为一谈。

同一机器和视口分别测冷编译、热 GPU 分项、CPU 准备、shader variant 数、材质／切线存储与 MRT 带宽；同时运行移动光照、纹理细节和辅助捕获序列。R0 建立基线后才冻结各阶段开销上限；超出预算时使用有记录的能力降级。既有 GGX 回归总时长不是材质性能基准。

本轮只落计划。后续首次实施以 R0 为边界，完成输入／覆盖与基准再交付，不把 R1–R5 一次性并入。
